# SEO audit implementation

This file maps the supplied audit recommendations to the rebuild.

| Audit recommendation | Implementation |
| --- | --- |
| Clear location + service H1 | Homepage H1 targets professional cleaning and construction services in București. |
| Dedicated service pages | Eleven detailed pages with unique copy, inclusions, process, FAQs and metadata. |
| Local landing pages | `/servicii-bucuresti/` and `/servicii-ilfov/`, internally linked from the footer. |
| Remove untrustworthy zero counters | Replaced with specific process and capability statements. |
| Strong calls to action | Quote CTAs throughout, direct call/email links and a mobile contact bar. |
| More useful lead form | Service, locality, approximate area, project description and up to four photos. |
| Company transparency | Legal company identifiers appear on the About page and site footer. |
| Technical metadata | Per-route title, description, canonical, Open Graph, robots directive and JSON-LD. |
| Structured data | LocalBusiness/HomeAndConstructionBusiness, Service, Article, CollectionPage, AboutPage, ContactPage, FAQ and Breadcrumb schemas where relevant. |
| Crawl discovery | Pre-rendered route HTML, build-generated `sitemap.xml`, `robots.txt`, `llms.txt`, `llms-full.txt` and per-route Markdown mirrors. |
| Internal linking | Service cards, related services/posts, local pages, contextual service-to-guide and guide-to-service links, plus quote links. |
| Romanian educational content | All nine published WordPress articles retained as local JSON and Supabase seed data. |
| Mobile conversion | Responsive navigation and persistent call/contact/quote bar. |
| Performance | Optimized WebP article images, self-hosted Latin Extended font subsets and immutable asset caching. |

Claims the audit could not verify—service area, phone number, address, Google Business Profile, testimonials, certifications and real project photos—were not fabricated. The launch checklist in `README.md` records the items that need owner confirmation.

External backlink acquisition requires verified accounts, real projects and owner outreach, so it is documented separately in `BACKLINK-AND-AI-SEO-PLAN.md` rather than simulated in code.
